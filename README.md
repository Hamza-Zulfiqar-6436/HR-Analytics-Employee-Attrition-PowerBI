# HR Analytics – Employee Attrition Analysis Using Power BI

## Project Overview
This project analyzes employee attrition patterns using HR data to identify key factors influencing employee turnover and provide actionable business insights.

## Objectives
- Measure overall attrition rate
- Identify departments and roles with high attrition
- Analyze the impact of age, income, overtime, job satisfaction, and work-life balance on employee attrition

## Tools Used
- Power BI
- Power Query
- DAX

## Key Metrics
- Total Employees: 1,470
- Attrition Count: 237
- Attrition Rate: 16.12%
- Average Monthly Income: 6.5K
- Average Tenure: 7 Years

## Key Insights
- R&D department has the highest employee attrition.
- Laboratory Technicians and Sales Executives show the highest turnover.
- Employees aged 26–35 experience the highest attrition.
- Overtime is associated with increased attrition.
- Lower job satisfaction and poor work-life balance correlate with higher attrition.

## Dashboard
The Power BI dashboard provides interactive visualizations with slicers for department, gender, and education.

## Dataset
IBM HR Analytics Employee Attrition Dataset (Kaggle)

## Outcome
This analysis helps HR teams identify attrition drivers and design data-driven retention strategies.
